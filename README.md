# Seguridad informática

Vulnerabilidades, ataques y defensas en el software, la web, las redes y los sistemas: modelo de amenazas, errores de memoria y su explotación, inyección, autenticación, privilegios, cadena de suministro, *fuzzing* y respuesta a incidentes.

**Ver en línea:** https://aaramirez.github.io/seguridad-informatica/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
